ollamyn API •

API multi-proveedor de IA, corriendo en Cloudflare Pages Functions.

Esta es la superficie pública. La API vive bajo /api.

  • /api/health — estado del servicio
  • /api/docs — referencia de la API
  • POST /api/register — crear cuenta
  • POST /api/login — iniciar sesión
  • GET /api/models — modelos disponibles
  • POST /api/chat/completions — hablar con la IA (streaming)
